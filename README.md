# 🎬 Online Movie Ticket Booking System

A web-based **Online Movie Ticket Booking System** developed using **ASP.NET Web Forms and C#**.

This project provides an easy and convenient platform for users to browse movies, login, book movie tickets, and view ticket confirmation.

The system also includes an **Admin Panel** for managing movie bookings and ticket information.

---

## 📌 Project Overview

The **Online Movie Ticket Booking System** is designed to simplify the traditional movie ticket booking process.

Users can access the website, view available movies, login to the system, and book movie tickets online without visiting the cinema ticket counter.

The system provides separate modules for **Users** and **Administrators**.

---

## 🚀 Features

### 👤 User Module

- 🔐 User Login
- 🎥 Browse Available Movies
- 📋 Movie Listing
- 🎟️ Online Ticket Booking
- 📝 Enter Booking Details
- ✅ Ticket Confirmation
- 📄 View Booking Information

### 🔑 Admin Module

- 🔐 Admin Login
- 📊 Admin Dashboard
- 🎬 Manage Movie Information
- 🎫 View Ticket Bookings
- 📋 Manage Booking Details
- ✅ Ticket Confirmation

### 🎟️ Booking Module

- Select Movie
- Enter Customer Details
- Enter Booking Information
- Confirm Ticket Booking
- View Ticket Confirmation
